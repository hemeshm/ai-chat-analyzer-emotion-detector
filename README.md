# Chat Analyzer and Emotion Detector

This project analyzes chat text and detects sentiment and emotions using Natural Language Processing (NLP) and Machine Learning techniques.

## Overview
The system processes chat messages and identifies emotional patterns such as positive, negative, neutral, joy, anger, sadness, fear, and surprise. It can be used to understand conversation trends and emotional tone from text data.

## Features
- Chat text preprocessing
- Sentiment detection
- Emotion detection
- Word frequency analysis
- Visualized output using graphs and word clouds

## Tech Stack
- Python
- NLTK
- VADER Sentiment
- Scikit-learn
- Pandas
- NumPy
- Matplotlib
- Seaborn
- WordCloud

## Folder Structure
- `src/` - main source code
- `sample_output/` - screenshots and result images
- `requirements.txt` - required Python libraries
